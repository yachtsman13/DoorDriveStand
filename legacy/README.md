# Исторические материалы

Здесь сохранены прежние версии проекта для прослеживаемости и сверки:

- `v5/` — производственные файлы, чертежи и исходники варианта v5;
- `v6-source/` — исходники `STEND_30x30` и `STEND_v6`;
- `v6-documentation/` — иллюстрации прежней документации;
- `src/` — отдельные исторические скрипты и вспомогательные генераторы;
- `notes/` — прежние заметки о проекте.

**Не использовать эти материалы для изготовления версии 3.0 / модели v7.**
В них встречаются отменённые решения, включая MGN12, устаревшие посадки и
прежнюю компоновку. Актуальная модель находится в корневом `src/`, а решения
владельца и блокирующие вопросы — в корневом `PLAN.md`.
