# Исходные материалы

## `source/STL/`

Геометрия исходных файлов Павла сохранена без изменений. Для использования в
`compose7.py` имена приведены к понятному виду:

- `8b1997c9_Karetka_1.STL` — «Каретка 1»;
- `0e66cd4e_Karetka_2.STL` — «Каретка 2»;
- `8f705e01_Upor.STL` — «Упор»;
- `f47c6753_Naznachenie_ne_podtverzhdeno.STL` — назначение не подтверждено.

В `source/SLDPRT/` сохранены пять исходных файлов SolidWorks с исходными
хэш-префиксами: имена с кириллицей в переданном архиве были потеряны.

## `photos/stand/`

Две фотографии действующего стенда версии 2.0.

## `photos/electronics-reference/`

Снимки описаний ESP32-плат, рассматривавшихся при обсуждении. Это справочные
материалы, а не утверждённая схема электрики или выбранный контроллер стенда.
