# Стенд проверки приводов дверей лифтов

Механический испытательный стенд для проверки обратных сигналов, работы
привода под нагрузкой и срабатывания реверса. Проект развивается отдельно от
Django-приложения LiftTeam; работа стенда не должна зависеть от Raspberry Pi
или от доступности сервера LiftTeam.

## Актуальное состояние на 15.11.2026

- **Версия 2.0** изготовлена в металле и используется в работе. Две фотографии
  действующего стенда — в `assets/photos/stand/`.
- **Версия 3.0** проектируется. Актуальная геометрия — **модель v7** в
  `src/model7.py`; прежние v5/v6 не являются основанием для изготовления.
- Рама 1500×300×300 мм из профиля 30×30 с пазом 8. Тормозной двигатель слева
  установлен на неподвижной плите, испытуемый привод справа — на сменной
  плите. Натяжение выполняется со стороны испытуемого привода через
  Г-образный толкатель под нижней ветвью ремня.
- Ремень HTD 5M-15, печатные шкивы 28T: делительный диаметр 44,56 мм,
  наружный — 43,42 мм. Посадка `bore=12` является **параметрической
  заглушкой**, а не подтверждённым размером вала.
- **Линейной направляющей MGN12 не будет.** Решение владельца от 15.11.2026:
  каретка закрепляется на верхней ветви ремня без рельсы.
- Пакет изготовления v7 (DXF/STEP/STL/чертежи) ещё не выпущен. Содержимое
  `legacy/` использовать для заказа деталей нельзя.
- Электрика, контроллер, методика автоматических испытаний и интеграция
  результатов с заказом на ремонт в LiftTeam ещё не спроектированы.

## Структура

| Каталог | Назначение |
|---|---|
| `src/` | Актуальная модель v7, её зависимости и просмотрщик |
| `docs/` | Исходный журнал передачи проекта от 14.11.2026 |
| `assets/source/` | Исходные STL и SLDPRT Павла |
| `assets/photos/stand/` | Фотографии действующего стенда |
| `assets/photos/electronics-reference/` | Снимки рассматривавшихся плат; не утверждённая схема |
| `renders/pulley/` | Актуальные рендеры шкива HTD 5M 28T |
| `legacy/` | История v5/v6 и прежние заметки; только для сверки |
| `out/` | Локально создаваемые GLB и снимки; в Git не входит |

`model.py`, `model2.py`, `model3.py` и `model4.py` содержат общие детали и
функцию проверки пересечений, необходимую `model7.py`. Самостоятельные модели
более ранних версий перенесены в `legacy/src/`.

Исходный `docs/Журнал_проекта_на_2026-11-14.md` сохранён как исторический
снимок. После переноса решения владельца уточнены здесь и в корневом
`PLAN.md`: рельса исключена, посадки остаются параметрическими заглушками,
измерения тормозного двигателя ещё не проводились.

## Запуск модели

Требуется Python 3. Зависимости указаны в `requirements.txt`.

```bash
cd DoorDriveStand
python3 -m pip install -r requirements.txt
python3 src/model7.py 600 0 pa --check
python3 src/pulley_htd.py a
python3 src/compose7.py out/m7_pa.glb out/m7_pa_composed.glb 600
```

Первый аргумент `model7.py` — положение каретки, второй — выдвижение узла
реверса (`0`/`1`), третий — метка результата. Дополнительные ключи:
`--open` открывает натяжитель, `--brakeslot` выбирает тормозную плиту с
прорезями, `--check` выводит найденные пересечения. GLB сохраняются в `out/`
рядом с каталогом `src/`, независимо от текущего рабочего каталога.
Основная сборка и отдельный шкив получают разные имена результатов.

`--check` — отчёт для конструктора, а не тест с исходом «прошло/не прошло».
При проверке переноса 15.11.2026 среди прочего выведены пересечения шкивов с
ремнём по 166,4 мм² и соленоида с перемычкой держателя 3120 мм². Первое
связано с упрощённым профилем зацепления и требует пробной печати, второе
нужно отдельно разобрать до выпуска держателя. Пересечения шпилек с гайками,
разъёмов с вилками и крепежа с планками являются контактами условных моделей
и не считаются самостоятельными ошибками без дополнительного разбора.

В `model7.py` есть собственная функция `pulley_htd()`, а отдельный
`pulley_htd.py` строит подробный шкив с ремнём и крепёжной ступицей. Перед
выпуском производственных файлов обе реализации профиля необходимо сверить;
автоматически считать их взаимозаменяемыми нельзя.

## Просмотр и снимки

Для `r.html` и `shot9.js` нужны Node.js, `three`, `playwright` и Chromium.
Устанавливать их следует в каталог стенда, чтобы работала карта импортов
`../node_modules/`:

```bash
cd DoorDriveStand
npm install three playwright
npx playwright install chromium
python3 -m http.server 8765
```

В другом терминале из того же каталога:

```bash
node src/shot9.js p1,p2,p3,p4 1
```

Снимки сохраняются в `out/`. Рендеры v7 всего стенда из прежней сессии
Claude в исходном архиве отсутствовали; здесь сохранены только четыре
актуальных вида шкива.

## Что нужно проверить до изготовления v7

1. Измерить сопротивление фазы и напряжение холостого хода ДСМ-0,18-500;
   без этого достаточность тормозной силы на шкиве Ø44 мм не подтверждена.
2. Получить размеры валов и фланцев двигателей. До этого менять только
   параметры посадок, не считая заглушки производственными размерами.
3. Проверить пробной печатью профиль HTD 5M 28T, зацепление и прочность
   печатного шкива.
4. Подобрать фактическую длину ремня, пружину натяжителя и ограничитель;
   проверить жёсткость Г-толкателя из алюминия 3 мм.
5. Выбрать соленоид 24 В с ходом 20 мм и доработать держатель.
6. Пересобрать пакет изготовления именно из v7 и актуализировать стоимость.
7. Отдельно спроектировать электрику, защиту, аварийный останов, сценарии
   испытаний и протокол результатов.
